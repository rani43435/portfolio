# Rani Marjy — Portfolio

A scroll-driven 3D portfolio: a tunnel of turning project screens, a flight down to the amber sphere, and a room where each project steps off the wall.

Live: https://rani43435.github.io/portfolio/

Projects: Harley, Maison Lin, Ambient Video, Germany Tour, Glance Pay.
Built with three.js. The visitor figure (`media/visitor.glb`) was modelled in Blender.
